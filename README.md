# 🌱 Kindred Circle

**Good things grow together.**

Kindred Circle is a community-driven event management platform where people can discover local events, participate in meaningful activities, and make a positive impact together.

From charity donations and winter relief to community cleanups and tree plantations, Kindred Circle makes it easier for people to connect, contribute, and create positive change.

## 🌐 Live Website

[Visit Kindred Circle](https://kindred-circle-frontend.vercel.app/)

## ✨ Features

- **User Authentication:** Sign up and sign in using email and password or Google authentication.
- **Browse Events:** Explore community events and discover opportunities to participate.
- **Search & Filter:** Find events using search and event categories.
- **Event Details:** View event descriptions, dates, locations, organizers, and volunteer information.
- **Join Events:** Authenticated users can join events and participate in community activities.
- **Joined Events:** View events you have joined.
- **Create Events:** Create and publish your own community events.
- **Manage Events:** Edit or delete events that you have created.
- **Volunteer Information:** View the volunteers participating in an event.
- **Upcoming Events:** Discover upcoming community activities.

## 🔐 Authentication & Security

Kindred Circle uses Better Auth for secure user authentication.

- Email and password authentication.
- Google OAuth authentication.
- JWT generation through the Better Auth JWT plugin.
- Backend JWT verification using JWKS.
- Protected API routes for authenticated users.
- Authorization checks for event management operations.
